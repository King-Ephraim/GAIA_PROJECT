Bienvenue sur le dépôt du site vitrine **DUNEKO** !

📝 Description

**DUNEKO** est un site vitrine conçu pour :
- Présenter les fonctionnalités du projet DUNEKO
- Expliquer le fonctionnement global de la solution
- Offrir un lien de téléchargement pour l’application mobile

Ce site est **responsive** et contient des **animations dynamiques**, dont un **diaporama de fond**, pour offrir une expérience utilisateur moderne et attractive.


## 🛠️ Technologies utilisées

- **HTML5**
- **CSS3**
- **JavaScript**


💡 Fonctionnalités principales

- ✅ Interface responsive (mobile & desktop)
- ✅ Un Menu avec les options: Accueil, Fonctionnalités, Comment ça marche, Télécharger
- ✅ Diaporama animé en fond d’écran  
- ✅ Animations fluides au scroll  
- ✅ Présentation claire des fonctionnalités  
- ✅ Lien de téléchargement de l’appli mobile
